5) ffmpeg / ffprobe (macOS) — NOT bundled
---------------------------------------------------------------------------
Reason:   No single official trustworthy universal static redistributable
          was added. Use Homebrew on the Mac that builds/runs the app:
            brew install ffmpeg
          (build_mac.sh already installs ffmpeg via brew when missing.)
          You may later drop ffmpeg/ffprobe into za-mac/tools/ if desired.

libmpv.dylib from Homebrew paths (see yu-medija-player.spec).
