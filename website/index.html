Your files play.
Your playlists stay in order.

A small desktop video player for Linux, Windows and macOS. libmpv playback for nearly any format, M3U and IPTV lists sorted into groups, subtitles in any language, screenshots and 0.25×–4× speed — with no background services and no effects pipeline.

Playlist on the left

Groups are read straight from the M3U, sorted and counted, so a 4,000-channel list stays usable. Hide the groups you never watch.

Controls that disappear

Fullscreen hides the bar until you move the mouse. Position is saved, so the next episode continues where you stopped.

One accent colour

Five themes share the same spacing and one amber accent. Readable in a dark room and in daylight, no decoration for its own sake.

Everything you need to watch something

Six view modes, two menus, keyboard first. No plugins, no background workers, no telemetry.

Almost every format

MKV, MP4, AVI, WebM, MOV, TS/M2TS, MPEG, WMV, FLV — anything FFmpeg can decode, played through libmpv. Hardware decoding is one switch in Settings.

M3U & IPTV playlists

Load a local .m3u/.m3u8 file or a remote URL. Channels collect into groups from group-title or #EXTGRP, with item counts per group.

Subtitles in any language

Embedded tracks and sidecar files (movie.en.srt, movie.bs.srt …) load automatically. OpenSubtitles search, delay and font size live in the CC menu.

Screenshot the exact frame

P saves a PNG or JPG of the current frame next to the video — or into a folder you pick in Settings.

Speed 0.25× to 4×

Eleven presets in the dropdown, [ and ] to step, R back to 1×. The player remembers the rate per session.

Live streams and URLs

Ctrl+U opens any stream URL. HLS/TS live streams are detected and kept alive, and a VLC user agent gets past picky IPTV panels.

Five themes, one layout

Cinema Dark, Midnight Teal, Graphite, Paper Light, Cloud Light. Same spacing and the same accent role in each — pick under View → Theme.

Keyboard first

Space, arrows, N/B, F, M, C — the whole player without the mouse. Files and playlists can be dropped on the window.

Small details that matter

Resume playback, repeat and shuffle, aspect-ratio modes, next/previous episode, remembered window layout.

Playlists that stay sorted

Drop in an M3U from your provider and the player builds a group for every group-title it finds. Groups keep their original order, show how many channels they hold, and can be hidden without touching the file.

  • group-title and #EXTGRP are both understood
  • Group filter with channel counts, plus a search box
  • Local files and remote http(s) playlists
  • Ctrl+P opens a playlist, N/B walks through it

Install

AppImage

chmod +x yu-medija-player-1.0.1-x86_64.AppImage
./yu-medija-player-1.0.1-x86_64.AppImage

Debian / Ubuntu

sudo apt install ./yu-medija-player_1.0.1_amd64.deb

Arch / CachyOS

sudo pacman -S mpv
./yu-medija-player-1.0.1-x86_64.AppImage

For the full format list, install libmpv — libmpv2 on Debian/Ubuntu, mpv on Arch/CachyOS. Without it the player falls back to Qt Multimedia and handles fewer formats. The bundles deliberately ship no FFmpeg or PipeWire of their own, so playback uses the versions your distribution already maintains.

Want it as your default player? The source archive includes scripts/install_appimage.sh, which copies the AppImage to ~/Applications, installs an icon and menu entry, and registers it for video files and M3U playlists.

Questions

Do I need mpv installed?

For the full format list, yes. The player uses your system libmpv — sudo apt install libmpv2 on Debian/Ubuntu, sudo pacman -S mpv on Arch and CachyOS. Without it the app still runs, through Qt Multimedia, but plays fewer containers and fewer IPTV streams.

Is there a Windows or macOS download?

Not in Releases yet — the workflow publishes Linux builds only. Both platforms build from source: PyInstaller with the bundled Inno Setup script on Windows, and scripts/make_dmg.sh on macOS. The code paths are in the repository.

Which Linux distributions work?

Any current 64-bit distribution that has FUSE, so the AppImage can mount itself: CachyOS, Arch, Ubuntu 24.04+, Mint, Fedora. The .deb targets Debian, Ubuntu and Mint. Bundled FFmpeg and PipeWire are deliberately left out so the player uses your system's, which is why it survives distribution upgrades.

Where are my settings stored?

In native per-OS settings — on Linux that is ~/.config/YuMedijaPlayer/Yu Medija Player.conf. Theme, volume, speed, window layout and resume positions live there; delete the file to start fresh.

Does it phone home?

No telemetry, no accounts, no update pings. The only network traffic is what you ask for: opening a stream or playlist URL, or an OpenSubtitles search.

What licence is it under?

GPL-3.0. Source, build scripts and the release workflow are all in github.com/elvedyn/Yu-Medija-Player.
